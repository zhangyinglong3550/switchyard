        网关重试（供应商级 · 对 Agent 透明）
        

          调用该供应商下模型失败时，网关先在本地重试可恢复错误，成功后再把结果返回给 Agent；不会把中间失败立刻甩给客户端。
          默认最多 3 次（网络失败 / 429 / 5xx）；流式仅在尚未写出内容前重试。下方模型可单独覆盖本设置。
        

        

          
          
        

      

      
      

        
可见 Agent

        
默认对全部 Agent 可见；选择特定 Agent 后，该供应商下的模型只会出现在这些 Agent 的模型列表里。

        

      

      

        
        
      

      

      

      

        
Sub2API 账号备份导入

        

          直接把 sub2api-data 备份导入到 Switchyard 的本机 Codex 账号池，由 Switchyard 自己轮询、故障换号并调用模型。
          不需要安装或运行 Sub2API，也不需要 API 地址、普通 API Key 或 Admin API Key。
        

        

          批量导入 Sub2API 账号备份
          

            选择一个或多个 JSON 后先在本机合并校验，再写入 ~/.switchyard/pools/。
            凭据不会写入供应商配置、请求日志或页面预览；支持 OpenAI OAuth 和 Agent Identity 账号。
          

          

            
            
          

          

          

            导入后保存当前供应商即可。从 Sub2API 导出的代理配置不会被复用；如需代理，请在本供应商的「代理地址」单独配置。
          

          
尚未选择备份文件

          

            
          

        

      

      

        
Codex OAuth（本机 ChatGPT 登录）

        

          复用本机 ~/.codex/auth.json（由 codex login / ChatGPT OAuth 写入）。
          状态检测看的是有效登录，不是只看文件在不在：
          access_token 未过期，或已过期但有可用 refresh_token 可自动续期，才算已登录。
        

        
检查登录状态…

        

          
          
          
        

        

          高级：粘贴 refresh_token 写入 ~/.codex/auth.json
          
          

            
          

          
会调用官方 token 端点换取 access，并回写 ~/.codex/auth.json。请勿把 token 发到聊天或日志。

        

      

      

        
Claude Official（对齐 CC Switch）

        

          与 CC Switch「Claude Official」相同：优先读取本机 Claude Code 登录态
          （macOS Keychain Claude Code-credentials，或 ~/.claude/.credentials.json 中的 claudeAiOauth）。
          请求走官方 api.anthropic.com，使用 Authorization: Bearer + anthropic-beta: oauth-2025-04-20。
        

        

          若未检测到登录：在终端执行 claude 按提示登录后点「刷新状态」。
        

        
检查登录状态…

        

          
          
        

        

          高级：浏览器 OAuth / 粘贴 refresh_token（不改 Claude Code 原登录）
          

            
          

          
          

            
          

          
高级凭证写入 ~/.switchyard/oauth/，不会覆盖 Claude Code 的 Keychain / .credentials.json。

        

      

      

        
账号池

        

          凭证保存在本机 ~/.switchyard/pools/，不会写入 config.json。
        

        
        

          
          
        

        
        

          
          
          
          
          
          
        

        

          「状态」= 健康度（健康/降级/冷却）；「额度」= 套餐剩余窗口（Codex 为 5h/周）；
          「Access」= OAuth 访问令牌过期时间，不是订阅日。鼠标悬停状态可看上次错误。
